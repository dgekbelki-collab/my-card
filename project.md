# Проект: Elena_Popova

## О проекте

Цифровая визитка-одностраничник для риелтора. Открывается по ссылке и сразу даёт клиенту три действия: позвонить, написать на почту, открыть страницу ВКонтакте. Учебный проект, на котором отрабатывается рабочий цикл из [workflow.md](../../workflow/workflow.md).

## Для кого

**Попова Елена** — частный риелтор в Соликамске, специализация — жилая недвижимость. Полное досье клиента: [dossier.md](dossier.md).

Целевая аудитория визитки — потенциальные клиенты Елены: люди, которые покупают, продают или подбирают квартиру в Соликамске и которым она передала ссылку или QR-код.

## Стиль дизайна

**Концепция:** премиум, тёмная тема, золотой акцент. Минимум декора, упор на типографику и фото.

**Палитра:**
- Фон: `#0b0d12` (основной), `#11141b` (карточка)
- Текст: `#f1ece3` (основной), `#8a857a` (приглушённый)
- Акцент: `#c9a574` (золото), `#e0bc8a` (золото-светлое)
- Границы: `rgba(255,255,255,0.08)`

**Композиция:** сетка `5fr / 7fr` — слева большое фото, справа информация. На мобильных — одна колонка, фото сверху с соотношением `5/4`.

**Типографика:** системные шрифты (`-apple-system`, `Segoe UI`, `Roboto`). Имя — крупный жирный заголовок с отрицательным трекингом.

**Декор:** мягкое золотое радиальное свечение по углам фона, скруглённые углы карточки (20px), глубокая тень. Анимация появления (`fadeIn 0.6s`), уважение к `prefers-reduced-motion`.

**⚠ Замечание по стилю:** «luxury»-эстетика (тёмное + золото) — стандартная для элитной недвижимости и ювелирки. Для рядовой жилой недвижимости в Соликамске может выглядеть как обещание премиума, которого нет. Возможный пункт для итерации.

## Принцип работы

Все правки идут по [рабочему циклу](../../workflow/workflow.md): один пункт за раз, после каждой правки — проверка в браузере и критика глазами пользователя. Не накидывать пачку изменений за раз.
